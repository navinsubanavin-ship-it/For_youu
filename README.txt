SNEHA'S LITTLE LOVE UNIVERSE

How to use:
1. Open index.html in a browser to preview the website.
2. To publish it free, create a GitHub repository and upload index.html, then enable GitHub Pages.
3. Share the published link with Sneha.

Features:
- Touch/click anywhere for a heart and sparkle burst.
- Tap the big heart to reveal a secret message.
- Floating hearts in the background.
- Mobile-friendly layout.
